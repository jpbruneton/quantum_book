Indices : `p` est conservé dans `E_p` (potencial) et `omega_p` (precesión).
`s` dans `mu_s` et `gamma_s` reste le symbole conventionnel du spin, même si le
mot courant est espín. Les indices d'axes, `L` (Larmor), `B` (Bohr), `e`
(electrón), les nombres et les étiquettes d'états sont conservés.

Registre académique, guillemets « … », medida pour la mesure physique.

SG sont traduits et cohérents avec le cours (notamment dos manchas, horno).
Aucune compilation effectuée. Les quatre rasters historiques restent en
`figs/fr/`, donc en repli non traduit ; les schémas SG sont en `figs/es/`.
