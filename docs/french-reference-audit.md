## Références existantes réparées dans le rendu web

Le site ne cherchait les labels que dans la leçon courante. Les références françaises entre leçons donnent maintenant le numéro de section, de définition ou d’équation, accompagné du thème et de la leçon/fiche. Un lien avec une ancre stable est ajouté uniquement si la cible est publiée. Les cibles privées encore hors ligne sont mentionnées « non publiée », sans lien.

Outre les nouveaux renvois, cela répare `l2n` dans la fiche 1, et `l2r`, `elemmat`, `def:op_adjoint_continu` dans la fiche 2 du thème 2. Les neuf liens inter-leçons présents ont une cible et une ancre vérifiées.

fichier n’existe pas dans le dépôt. Le renvoi à la « sous-section suivante sur

- [Colbeck et Renner (2012)](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.108.150402) : article original sur la correspondance entre fonction d’onde et réalité.

réussis, contrats de contenu réussis. Les neuf liens français entre leçons ont une

signale l’écart attendu décrit ci-dessus ; les catalogues d’interface sont valides.
